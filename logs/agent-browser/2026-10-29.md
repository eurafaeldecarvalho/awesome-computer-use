## Commands

```bash

agent-browser fill "#email" "ada@example.com"
agent-browser fill "#city" "London"
agent-browser download "#download" /tmp/ab-run/downloads/result.csv
agent-browser get text "#status"
agent-browser get text "#csv"
```
