# Logs

A file appears here only after this repository actually installed or ran that project.

The shared-task status in `data/entries.yml` stays `not_tested` unless the log shows an agent attempting [`bench/tarefa.md`](../bench/tarefa.md), with a step count and a cost per step. Driving a CLI by hand is a verified run of the tool, and the log says so. It is not a tested agent.

Screenshots are not stored in these logs.
